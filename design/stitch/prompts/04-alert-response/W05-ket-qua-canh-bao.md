# W05 — Kết quả cảnh báo

Tạo responsive web page cho alert đã được giải quyết.

**PLATFORM:** Responsive web, mobile-first 390 px; centered desktop container.

**USER GOAL:** Hiểu alert kết thúc như thế nào và biết không cần hành động thêm.

**DEFAULT STATE:** Minh Anh an toàn, được Lan xác nhận.

**PAGE STRUCTURE:**

1. Minimal header với logo.
2. Status “Đã giải quyết” kết hợp icon và text.
3. Heading “Minh Anh đã an toàn”.
4. Explanation “Lan đã xác nhận tình trạng lúc 08:42, 03/08/2026. Bạn không cần thực hiện thêm hành động.”
5. Summary:
   - “Cảnh báo bắt đầu: 08:15”.
   - “Được tiếp nhận: 08:27 bởi Lan”.
   - “Đã giải quyết: 08:42”.
6. Thank-you message.
7. Secondary action “Đóng trang”.
8. Footer có alert reference và Privacy.

**VARIANTS TO SUPPORT LATER:** User self-checked-in, another contact is handling, expired link, invalid link and completed drill.

**CONSTRAINTS:** Không action lại trên resolved alert; không confetti; không hiển thị provider ID hoặc dữ liệu nhạy cảm. Dùng design system web hiện có.
