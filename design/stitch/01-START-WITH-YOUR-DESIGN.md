# Điền màn hình Start with your design

## Paste existing DESIGN.md

Ưu tiên nhấn **Upload a DESIGN.md file** và chọn:

```text
design/stitch/DESIGN.md
```

Nếu upload không hoạt động, mở `DESIGN.md`, copy toàn bộ và paste vào ô “Paste a DESIGN.md file here”. Không upload và paste đồng thời.

## Drag and drop files

- `Upload a DESIGN.md file`: dùng.
- `Upload code, images, fonts and logos`: để trống ở giai đoạn này.
- `Upload a .fig file`: để trống vì chưa có Figma source.

## Public GitHub repository

Để trống. Repository hiện tại là private:

```text
https://github.com/MinhThienNguyen040905/im-okay
```

Ô này trong Stitch đang yêu cầu public repository. Không chuyển repo thành public chỉ để sử dụng bước này.

## Add website

Để trống cho tới khi có một website hoặc prototype được host công khai.

## Additional instructions

Mở `02-ADDITIONAL-INSTRUCTIONS.md`, copy phần nằm dưới tiêu đề “Nội dung cần dán” và paste vào ô Additional instructions.

## Continue

Trước khi nhấn Continue, kiểm tra:

- DESIGN.md đã xuất hiện như một file được chọn hoặc đã được paste.
- Additional instructions đã có nội dung.
- Không có GitHub URL private trong ô public repository.
- Không upload file chứa secret, `.env`, API key hoặc thông tin cá nhân thật.
